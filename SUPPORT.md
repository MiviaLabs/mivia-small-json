# Support

- **Bug reports and feature requests**: open a GitHub issue (templates
  provided).
- **Security vulnerabilities**: never in public issues — see
  [SECURITY.md](SECURITY.md) for private reporting.
- **Questions and usage help**: open a GitHub Discussion or a issue tagged
  `question`.
- **Commercial hosting**: MiviaLabs runs a hosted API of this model at
  https://api.mivia.app/v1/models/mivia-small-json — see
  https://mivia.app.
