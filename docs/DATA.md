# Data

What ships in this repository, what does not, and how to rebuild what does not.

## What ships

- `data/synthetic/` — the seeded synthetic training/dev corpus generated by
  `python -m mivia_small_json.synth`. Original content, no upstream source.
- `data/heldout/` — the frozen held-out splits used by the test suite
  (synthetic records and the span-fill reserve).
- `tests/fixtures/` — captured pipeline behavior fixtures, regenerated by
  `tests/fixtures/make_routing_golden.py` over the sources above.

## What does not ship, and why

The model was trained and measured on public corpora whose licenses do not
all permit redistribution inside an Apache-2.0 repository, and on GitHub-
sourced text that carries third-party copyright and contributor personal
data. None of it is redistributed here. Every source keeps a deterministic
builder script under `scripts/`; fetch the upstream, run the builder, and
you have the corpus.

| Source family | Role | License (upstream) | Builder / fetcher |
|---|---|---|---|
| LogHub 2k per-system logs | log_event train/eval | research/academic-only (GitHub dist); Zenodo dist is CC-BY-4.0 | `scripts/fetch_data_phase1.py`, LogHub fetchers |
| Berkeley Function Calling Leaderboard (BFCL) | tool_call pairs, guard eval | Apache-2.0 | `scripts/build_tool_match_corpus.py` |
| Glaive function-calling v2 | tool_call train | Apache-2.0 | `scripts/fetch_data_phase1.py` |
| GitHub issues / commits / pull requests (scikit-learn, flask, requests, fastapi, pytest, …) | issue/commit/pull_request train + eval | per-repo OSS licenses; contributor text and emails — not for republication | `scripts/fetch_pr_training_data.py`, `scripts/fetch_issue_negatives.py`, `gh`-based fetchers |
| Banking77 / WolBanking77 / Amazon MASSIVE | intent selection train/eval | CC-BY-4.0 | `scripts/build_intent_pairs.py` |
| CLINC150 | intent selection train/eval | no redistribution grant found — not shipped | `scripts/bench_clinc150_select.py` (eval only, fetch on demand) |
| Multilingual intent tickets (authored) | multilingual routing train | original authored content | `scripts/build_multilang_tickets_v10.py` |
| NVD / GitHub Security Advisories | security grading | public domain / CC-BY-4.0 | `scripts/fetch_nvd*.py`, GHSA fetchers |
| SWE-bench Lite subset | routing/eval | MIT (code); dataset license undeclared — fetch on demand | `scripts/bench_swebench.py` |
| Real-world evaluation slices (chat, Slack-style, post-commit, multilingual) | pre-registered eval floors | mixed public sources; see `scripts/collect_realworld_slices.py` for per-slice sources | `scripts/collect_realworld_slices.py`, `scripts/build_realworld_r1_corpus.py` |

The governing rule for any future data work: a builder must declare its
sources, admission rules, minimum contribution, and eval-window exclusion
before it runs, and it must fail rather than silently ship less than it
declared. Eval surfaces stay disjoint from training data by construction,
verified by normalized-set comparison in the data gates.

## Provenance and licensing

- Model weights are fine-tuned from `microsoft/Multilingual-MiniLM-L12-H384`
  (MIT) and `cross-encoder/ms-marco-MiniLM-L-6-v2` / `-L-12-v2` (Apache-2.0);
  see [NOTICE.md](NOTICE.md).
- No third-party dataset is redistributed by this repository, so no dataset
  attribution obligation attaches to copies of it. If you rebuild corpora
  with the builders above, the upstream licenses listed here — and any
  NOTICE requirements they carry — apply to your copies.
- The shipped artifacts that feed the served decision layers are listed with
  their sha256 sidecars in `models/SHIPPED.json`.
